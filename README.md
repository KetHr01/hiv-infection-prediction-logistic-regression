# HIV Infection Prediction Using Logistic Regression

## Overview
This project is a bachelor thesis focused on predicting HIV infection status using machine learning methods.

## Dataset
The dataset contains medical and demographic information of patients.

Target variable:
- infected — HIV infection status

## Technologies
- Python
- Pandas
- NumPy
- SciPy
- Scikit-learn
- Statsmodels
- Matplotlib

## Project Workflow
- Data preprocessing
- Handling missing values
- Encoding categorical features
- Feature scaling
- Feature selection (Forward and Backward Selection)
- Logistic Regression model training
- Model evaluation

## Evaluation Metrics
- F1-score
- Precision
- Recall
- Confusion Matrix
